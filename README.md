# RLC Premier Financial Consulting — Figma social media template

This repository holds the creative brief for an editable Instagram graphic template for RLC Premier Financial Consulting. The template is intended for weekly financial guidance posts aimed at small-business owners in Central Texas.

## Figma brief

> Figma, create an editable social media graphic template for RLC Premier Financial Consulting. Target small-business owners in Central Texas. Use a professional, approachable style with a bold headline, space for useful financial guidance, a small bee design element, and a placeholder for our actual logo. Make a 1080 × 1350 Instagram version. Keep text editable and the layout reusable for future weekly posts.

## Design requirements

- Canvas: 1080 × 1350 pixels, suitable for an Instagram portrait post.
- Audience and tone: Central Texas small-business owners; professional and approachable.
- Layout: a prominent headline and a flexible area for useful financial guidance.
- Brand elements: a small bee accent and a placeholder to replace with the actual RLC logo.
- Reuse: keep all copy editable in Figma and organize the layout so the headline and guidance can be changed for each weekly post.

The Figma design and actual logo are not included in this repository yet.
